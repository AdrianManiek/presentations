# Presentations

A collection of slides and materials from talks I've given at various events, meetups and conferences.

## Structure

Presentations are organized by event, with a separate subfolder for each edition or meetup:

```
presentations/
└── <event>/
    └── <edition>/
        └── <presentation files>
```

Browse the folders to find the materials from a specific event.
